# Перенос дашборда Mocheqi на сервер

Дашборд переезжает с вашего компьютера на сервер (сервер брата на TimeWeb, Ubuntu). После переезда он работает круглосуточно, сотрудники открывают его по ссылке с телефоном и паролем, а новые версии сервер сам забирает с GitHub каждые 5 минут. Установка — один раз, примерно 20–30 минут.

## 1. Что получится

- **Программа** — в папке /opt/mocheqi/dashboard на сервере, работает как служба: запускается сама после перезагрузки сервера и перезапускается при сбое.
- **Загрузки по расписанию** (время московское): ночная — 05:00; цены и статусы поставок — 10:00, 14:00, 18:00; заказы за сегодня — каждые 30 минут с 07:00 до 23:30. Компьютер и VPN больше ни при чём.
- **Обновления** — каждые 5 минут сервер проверяет GitHub (репозиторий nadegdakorneeva-coder/mocheqi). Есть новая версия — скачивает, проверяет и перезапускает дашборд. Если новая версия с ошибкой — остаётся старая.
- **Резервная копия базы** — каждую ночь в 03:30, хранятся 14 последних (папка data/backups).
- **Ключи и база** живут только на сервере, в GitHub не попадают. Файл ключей config.ini закрыт для всех, кроме программы.

## 2. Что нужно заранее

| Что | Где взять | Кто |
|---|---|---|
| Адрес сервера (IP), логин и пароль с правами sudo | у брата (панель TimeWeb) | брат |
| Ubuntu 22.04 или 24.04 на сервере | проверить: lsb_release -a | брат |
| Вход в GitHub под аккаунтом nadegdakorneeva-coder | github.com | вы |
| Программа WinSCP на вашем компьютере | winscp.net, бесплатно | вы |
| Домен (по желанию), например dash.mocheqi.ru | любой регистратор; запись A → IP сервера | вы / брат |

**Про домен.** Без домена дашборд откроется по адресу вида http://IP:8765 — работает, но без шифрования. С доменом скрипт сам сделает https (замок в браузере). Запись A для домена нужно создать **до** установки: в панели регистратора домена — тип A, имя dash (или @), значение — IP сервера. Применяется от 15 минут до нескольких часов.

Пароли от сервера и GitHub никому не пересылайте, в том числе Claude. Ниже везде вводите их сами.

## 3. Шаг 1. Загрузить установщик на сервер

1. Откройте WinSCP → «Новое подключение»: протокол **SFTP**, имя хоста — IP сервера, порт 22, имя пользователя и пароль — от брата. «Войти».
2. Слева — ваш компьютер, справа — сервер (домашняя папка пользователя, например /home/ivan).
3. Слева откройте **D:\MP\dashboard\server** и перетащите файл **install.sh** направо.

## 4. Шаг 2. Запустить установку

1. Откройте терминал на сервере. Проще всего — в WinSCP кнопка **«Открыть сессию в PuTTY»** (значок с двумя мониторами), или в Windows: Пуск → PowerShell и команда ниже (IP и логин — свои).
2. Запустите установку и введите пароль пользователя, когда спросит (символы при вводе не видны — это нормально).

```bash
ssh ivan@123.45.67.89
sudo bash install.sh
```

Скрипт пройдёт 8 шагов. Остановится он дважды:

> **Остановка 1 — ключ для GitHub**
>
> Скрипт покажет строку, которая начинается с **ssh-ed25519** и заканчивается на **mocheqi-server**. Это ключ «только чтение» — по нему сервер скачивает программу.

> 1. Выделите строку мышью (в PuTTY выделение сразу копирует).
> 2. В браузере, в аккаунте nadegdakorneeva-coder: репозиторий **mocheqi → Settings → Deploy keys → Add deploy key**.
> 3. Title: **server**. Key: вставьте строку. Галочку **Allow write access НЕ ставьте**. «Add key».
> 4. Вернитесь в терминал и нажмите **Enter**. Если ключ принят — установка пойдёт дальше; если нет — скрипт покажет ключ снова.

> **Остановка 2 — домен**
>
> Впишите домен (например dash.mocheqi.ru) и Enter. Нет домена — просто Enter: дашборд будет по IP.

> Если на сервере уже есть сайт брата на nginx — скрипт добавит дашборд отдельным сайтом и не тронет остальные. Если порт 8765 занят — возьмёт следующий свободный и напишет какой.

В конце скрипт напишет **адрес дашборда**. Пока база пустая — это нормально, переносим её на следующем шаге.

## 5. Шаг 3. Перенести базу и ключи с компьютера

1. На компьютере запустите **D:\MP\dashboard\server\prepare_transfer.bat**. Он попросит закрыть окно дашборда (start.bat) и виджет, аккуратно закроет базу и сложит два файла в папку **server\to_upload**: config.ini (ключи) и mp.sqlite (база: история, пользователи, отметки).
2. В WinSCP перетащите **оба файла** из to_upload в домашнюю папку на сервере (туда же, где install.sh). База весит около 250 МБ — загрузка займёт пару минут.
3. В терминале выполните команду ниже. Она переложит файлы на место, закроет к ним доступ и перезапустит дашборд.
4. На компьютере **удалите папку to_upload** — в ней ключи.

```bash
sudo bash /opt/mocheqi/dashboard/server/after_upload.sh
```

## 6. Шаг 4. Проверить и раздать доступ

1. Откройте адрес дашборда, войдите своим телефоном и паролем — должны быть все данные, как на компьютере.
2. Нажмите «Обновить данные» слева внизу — через несколько минут в строке статуса появится «Готово». Это проверка, что сервер достаёт до WB и Ozon.
3. Сотрудникам: «Прочее → Пользователи» → создать (или уже есть) → галочки нужных разделов. Им — ссылка, телефон и пароль.

## 7. Шаг 5. Отключить загрузки на компьютере

- Запустите **D:\MP\dashboard\remove_schedule.bat** — удалит задачи Windows (ночная загрузка, цены, заказы). Иначе компьютер и сервер будут дважды дёргать API маркетплейсов, а WB за частые запросы ограничивает.
- start.bat на компьютере больше не запускайте: там остаётся старая копия базы, изменения в ней на сервер не попадут.
- Виджет пока читает базу компьютера — переключим его на сервер отдельным обновлением.

## 8. Как идут обновления

- Claude выкладывает новую версию в GitHub → в течение 5 минут сервер её скачивает и перезапускает дашборд. Ничего делать не нужно; страницу в браузере достаточно обновить (F5).
- Журнал обновлений: /opt/mocheqi/dashboard/data/update_log.txt.
- **Откат**, если новая версия чем-то мешает (вернёт прошлую и остановит автообновление):

```bash
sudo /opt/mocheqi/dashboard/server/update.sh --rollback
# снова включить автообновление:
sudo /opt/mocheqi/dashboard/server/update.sh --resume
```

## 9. Полезные команды (для брата)

| Зачем | Команда |
|---|---|
| Работает ли дашборд | systemctl status mocheqi |
| Последние сообщения дашборда | journalctl -u mocheqi -n 50 --no-pager |
| Перезапустить дашборд | sudo systemctl restart mocheqi |
| Расписание загрузок | systemctl list-timers 'mocheqi-*' |
| Запустить ночную загрузку сейчас | sudo systemctl start mocheqi-daily |
| Журнал загрузок | tail -n 50 /opt/mocheqi/dashboard/data/collector_log.txt |
| Резервные копии базы | ls -lh /opt/mocheqi/dashboard/data/backups |
| Поправить ключи WB/Ozon | sudo nano /opt/mocheqi/dashboard/config.ini, затем перезапустить дашборд |

Повторный запуск install.sh безопасен: он ничего не удаляет, только досоздаёт недостающее (например, если позже появится домен).

## 10. Если что-то пошло не так

- **«Добавьте этот ключ в GitHub» повторяется** — ключ добавлен не в тот репозиторий или не полностью скопирован. Проверьте: mocheqi → Settings → Deploy keys, строка должна быть одна, от ssh-ed25519 до mocheqi-server.
- **https не получился** — домен ещё не указывает на сервер (запись A не создана или не применилась). Подождите и запустите install.sh ещё раз.
- **Дашборд открывается, но данных нет** — не выполнен шаг 3 или база загружена не в домашнюю папку. Повторите шаг 3.
- **«Обновить данные» заканчивается ошибкой** — смотрите журнал загрузок (таблица выше). Частая причина — неверные ключи в config.ini.
- **Сайт не открывается по IP** — у TimeWeb может быть включён брандмауэр в панели: откройте входящий порт 8765 (или тот, что написал скрипт).

Пришлите Claude текст ошибки или скриншот терминала — без паролей и ключей.
